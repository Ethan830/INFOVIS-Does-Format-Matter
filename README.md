Results for experiment are store in results folder.  
DAT-_PAR.py is script that translates CSV data table to TXT descriptive paragraphs  
DAT-_VIS.py is script that translates CSV data table to PNG rendered image  
Ground-Truth stores the ground truth for our questions  
Result-Excel.py is script that extracts confidence scoring from the results into excel  
Question.py stores the question for each data set  
Main.py is the script that adminsters the input and question to each model's API  
Linear Mixed Effect Model (LMEM) folder stores LEMEM results and python script for LMEM analysis (LMEM.py)
